Автоподгрузка ключей из GitHub
Ссылка на файл в репозитории: откройте файл на GitHub → «Raw» → скопируйте адрес. Репозиторий должен быть публичным, иначе браузер не заберёт файл без токена.
Файл в репозитории зашифрован AES-GCM: без пароля ключи из него не достать. Короткий пин из 4–6 цифр бот подберёт за секунды — лучше 12+ знаков.
Кнопка «Собрать файл» берёт ключи из списка выше, шифрует паролем и скачивает готовый keys.enc.json — его останется положить в репозиторий.
